# IPinfo.dog 界面规范

更新：2026-11-17。适用于“我的 IP”与“IP 查询”的桌面和手机界面。后续界面开发先读本规范；用户新要求优先，修改规范后再调整共用样式，不能各组件自行选一套字号。

## 目标与边界

现有品牌角色、奶白图标、Neutral黑白灰和浅 /深 /跟随设备保持。界面先给IP结果，再给网络信息和来源差异。不加入无数据依据的评分、状态灯或竞品扩展功能，不用装饰卡片填空。

主卡最多一层容器；地区 /ASN已经在摘要或资料中展示时，不再做两张重复摘要卡。桌面内容宽度1120px，手机内边距16px；正文左对齐，数值与同类字段保持一致对齐。正文浅深主题沿用项目tokens，不另加一组任意灰色。

## IPX参考与本站决定

参考：[IPX实际站点](https://ipx.al/)，2026-11-16读取其浏览器版本公开CSS。初次动态界面可见，但后续IAB标签崩溃，未完成其双断点computed-style验收；以下是CSS声明值，不能声称是所有语言 /设备的完整实测。

| 对象 | IPX公开CSS声明 | 本站采用 |
| --- | --- | --- |
| 主IP | `.ip` 30px /600 /1.15，≤600px为24px | 桌面30px /手机24px，700 /1.25，保持本站字形 |
| 摘要 | `.place` 13px，次要色 | 13px，次要色 |
| 栏目标题 | `h3` 12px /600，次要色，底间距6px | 14px /600 /20px，正文色，底间距8–12px |
| 列表正文 | body继承13px /1.5；部分数值500 | 13px /400 /20px |
| 表头 | `th` 11px /500，次要色 | 12px /500 /16px，次要色 |
| 辅助文字 | 多处11–12px | 表内更新沿用13px；补充辅助12px，许可11px |
| 数据行 | td上下5px | 本站桌面上下6px、表头28px；手机三列对齐，上下6px，普通行32.5–33px |

参考的是层级、权重与密度，不能简单断言IPX所有标题都比正文大。本次用户明确反馈标题弱于列表，因此本站栏目采用14px并保证字重高一级。IPX缩小长IPv6等做法不照搬：本站地址完整换行，手机不能靠极小字号塞入宽表。

## 统一文字令牌

实现唯一入口：[globals.css](../src/app/globals.css) 的 `report-*` 共用样式。组件使用语义class，不重新填任意字号来覆盖。

| Class | 用途 | 尺寸 /字重 /行高 |
| --- | --- | --- |
| `report-ip` | 主IP，等宽 | 手机24px、≥640px 30px /700 /1.25 |
| `report-section-title` | 网络信息 /多源对照 | 14px /600 /20px |
| `report-data` | 网络值 /来源 /城市 /ASN /出口 | 13px /400 /20px |
| `report-table-label` | 表格列名 | 12px /500 /16px，次要色 |
| `report-meta` | 补充时间、辅助说明 | 12px /16px，次要色 |
| `report-license` | 来源许可链接 | 11px /16px，次要色，不用于核心结果 |

层级顺序：主IP > 栏目标题 > 列表正文 > 表头 /辅助。禁止表头比栏目标题更大或更粗；不要把所有文字都加粗。字号不得按“手机就缩小”无下限压缩；手机正文仍13px，手机主要交互按钮至少44px。IP地址用等宽，ASN列保持数字对齐，普通组织 /城市名用系统无衬线。

## 响应式与内容规则

- 必验320、390、768、1440px。手机页面及所有可见内容容器均不得横向溢出；不以隐藏滚动条 /全局overflow-x:hidden掩盖。
- 多源桌面来源 /国家城市 /ASN /更新固定比例；手机采用来源 /检测结果两列紧凑表格（34% /66%），地区与城市同行；按IPX手机格式不显示ASN /更新两列，桌面仍保留ASN及更新，AS值完整，读屏保留本行元数据。来源排序 /加载 /错误 /重试不变，不能从数据契约中删除元数据或删掉来源。
- 城市 /组织长值完整换行；不用省略号或截断藏掉差异。旗帜使用本地4:3矩形资源，不用fis方形变体或圆形裁切；与文字留6–8px间距，未知地区不拿注册地代替。多源ASN值统一完整`AS212336`格式，缺失显示—；API保留数值契约。
- IPv6按地址组换行，不做横向滚动。IPv4末两段、IPv6末四组以星号遮挡，显示 /隐藏共用稳定占位；主卡 /摘要 /对照行几何不能改变，完整复制 /结果链接不受遮挡影响。
- 页脚左侧©年份与站名，右侧简短浏览器直连说明；来源 /必要许可在对应多源行，不重复第三方引用。手机页脚不能滚动。
- 首页在同一张多源表内所有来源连续排列，国内来源优先放在最前，不保留国内外或来源类型分组与标记。全表只用一组表头，结果栏统一显示国家城市，已有来源字段优先，缺失字段由本站MaxMind补齐；城市仅在国家一致或来源未提供国家时补齐；原始出口IP及差异状态保留于提示与读屏文本，取消反复的类型表头和分组底色。回显行统一显示观测地址对应国家城市，原始地址与差异状态保留于提示，遮挡同步生效。独立查询只列目标地址的归属地来源。
- 首页协议选项采用共用ToggleGroup的segment变体，外层胶囊、选中项前景色填充 /背景色文字，未选中次要色；13px文字，手机44px /桌面28px按钮高度，方向键移动焦点、空格确认选择，当前项不可取消成空值。
- 首页IPv4 /IPv6与独立查询共用同一有序来源清单。双栈回显成功但族不匹配时保留“未获取所选协议结果”及重试，不把另一族地址伪装成当前结果；加载 /失败不丢行。独立查询对只接入当前连接回显的来源保留名称并标“仅支持当前IP检测”，不请求访客回显、不给这些行填国家城市 /ASN；能按目标查询的源真实查询目标，国内四项顺序固定。
- 骨架、取得地址、资料完成三个阶段共用标题结构；骨架预留旗帜和同字号行高，工具栏预留操作区宽高。固定视口中卡片顶边和IP首行起点不得位移；长IPv6可自然扩展下方高度。资料状态切换不能重新播放整卡淡入。
- 多源对照所有来源链接统一使用SourceLink：名称13px、右侧同一10px外链箭头、间隔4px；箭头不可单独掉到下一行，长名称在剩余宽度完整换行。两种来源、两页和加载 /错误状态保持同一入口与可见标识。
- 来源失败只影响自身，错误和重试在本行；骨架对应真实请求。保留读屏状态 /焦点 /取消竞态，遵循减少动态效果偏好。

## 每次UI变更的验收记录

1. 在已有内置浏览器 /服务验收，不另启动无头Chrome。固定公共IPv4与IPv6、真实首页、长城市 /组织、缺失字段分别检查；真实出口证据只留ops。
2. 320 /390 /768 /1440px记录整页与所有可见容器的clientWidth /scrollWidth。任何超过1px的横向溢出均不通过；隐藏的桌面版本 /读屏专用1px节点不计为可见内容，原生输入框内部编辑长地址不算结果横向滚动。
3. 记录三类区域的computed font-size /font-weight /line-height；栏目14 /600、正文13 /400、表头12 /500。深浅主题分别截图，不把缩放截图当作CSS字号。来源数量由当前来源清单声明，桌面 /手机都须完整保留，不能硬编码三行或直接丢弃字段适配。
4. 比较同协议隐藏 /显示前后的卡片、标题、摘要与出口行矩形；除内容本身外无位移。检查刷新、语言切换、最近记录、独立重试和完整复制。
5. 执行现有单元、lint、build、typecheck；部署时完成既定正常网络候选 /公网。截图 /测量 /未验范围进入任务归档，更新PROGRESS并读回。HTTP或Mock通过不能冒充浏览器 /真机验收。

规范本身不能替代执行证据。新UI没有手机可见容器和字号实测，不记“视觉验收通过”；未获用户视觉接受时单独保留待反馈状态。

## 可复用浏览器检查

[scripts/check-report-ui.mjs](../scripts/check-report-ui.mjs) 导出只读DOM审查函数，不启动浏览器。复用已打开的本站结果页，在CUA会话导入 `auditReportUi` 并执行 `tab.playwright.evaluate(auditReportUi)`；每个必验断点都要求 `ready === true` 且 `violations.length === 0`，输出归档。它检查实际computed字号 /字重 /行高、页面与可见容器溢出、手机完整来源数量、重复摘要、页脚引用、矩形旗帜和完整AS前缀。`measureReportAnchor`可在骨架 /地址 /详情阶段分别采样，固定视口比较toolbar、card与address起点。

它不能替代截图审视、显隐矩形比较、交互 /主题 /三语 /错误状态及真机检查。不是Node单元测试，不把该文件直接作为Node DOM脚本执行，也不为此新建Chrome。

## 本次落地记录

规则已用于两个现有页面，具体改动、测试与公开截图见 [M1-11本次验收](archive/m1/m1-11-result-card-layout/visual-refinement.md)。后续修改必须更新本规范、共用样式与对应任务证据，不能只改其中一处。

2026-11-16密度补充：多源标题到表格8px，主体桌面内边距20px，手机16px。先压缩留白，不降低正文13px或手机44px主要操作尺寸；来源数量按实际清单，不加入无法直连或重复同源的占位来源。在线第三方资料请求由浏览器发出，无本站代理回退。

IPinfo本地库恢复：来源数量为MaxMind /IPinfo Lite /IPQuery /FreeIPAPI四行；IPinfo显示数据库构建日期、城市留空，过期只影响本行。按用户反馈不单独展示BY-SA许可文字，保留IPinfo来源外链及提示。Logo仅同地址 /相同ASN配对，不因加载图标改变IP位置。

本轮内置浏览器补验：IPX在390px下多源正文13px /19.5px、表头11px /16.5px、标题12px /18px，td上下5px，普通行30.5px，ASN /更新为display:none。本网站仍采用统一14 /13 /12px层级，普通行32.5–33px；当时手机三列44% /23% /33%，不保留额外可见辅助行，矩形旗帜不变。详见[M1-11手机对照](archive/m1/m1-11-result-card-layout/mobile-comparison.md)。

手机列宽为适配统一外链图标采用34% /66%，结果栏合并地区与城市，按词自然换行，极长单词仍可断行。

独立查询的搜索框位于报告工具栏上方，手机占满可用宽度，滚动时吸顶。提交成功后地址、标签页标题和输入框同步，浏览器前进或后退恢复相应报告。校验失败在输入框旁提示，保留当前报告和分享链接。验收时至少连续换查两个地址，再输入无效值并后退。

ASN按用户确认保留桌面列和完整AS前缀，窄屏隐藏可见列时仍保留读屏与行提示；来源自带ASN优先，缺少时用同地址本站资料补齐。
