# M2-01：IPv6 就绪检测

日期：2026-11-13。状态：实现与可执行验收完成、最终版已上线；新增页面待用户视觉反馈，条件环境补验保留。用户在 M1 收尾后要求继续下一项，启动 M2；不扩展为一次实现全部 M2。

目标：独立 /ipv6 页面，复用直连 IPv4 / IPv6 探测并观察本次主站请求的实际出口协议，提供三语、单项 / 全部重测、取消与 HTTPS 请求耗时。保持已接受的 Neutral 风格与免登录。不保存诊断地址到最近查询。

真实连接来源仍只接受认证入口，不把访客转发头当来源；主站使用 Cloudflare 还原来源，缺失 / 异常返回不可用，不猜测。仅本次观测双栈出口可达，不声称无代理 / 原生双栈。超时、跨源受限、限流、取消独立记录。请求耗时不是 ICMP Ping，也不代表协议速度排名。

开发与浏览器测试、部署 / 公网验收和用户视觉反馈分别记录。已完成 114 项单元测试、工程 / 本地浏览器、真实双栈浏览器与最终发布后 18 项 HTTP / 24 项原功能回归；各版本与证据边界分开记录。运维原件只入本地 ops 同编号目录。


## 实际实现

- /ipv6 与主站导航 / 首页入口；IPv4、IPv6 与主站连接独立状态，单项 / 全部重测和取消，完整 IP 显示 / 隐藏 / 复制；简 / 繁 / 英与主题沿用。
- /api/connection 复用入口认证 / 公共地址 / 无参数 / 无共享缓存 / 预算；新的 Caddy 路径只在主站可信入口注入来源，既有 v4 / v6 严格模式保持。方案与限制见 [检测口径](design.md)。
- 5 秒超时、请求代次 / 取消隔离；计时只表示 HTTPS fetch 耗时，主站请求协议可能与直连不同，不把单次失败写成永久不支持。
