# M2-UX-01：全站前端文案精简

日期：2026-11-13。状态：五页实现、三语、当前环境测试与香港发布完成；这轮视觉 / 阅读效果待用户反馈。

用户要求全面减少无关描述和理解负担，随后明确不要反复标识 GeoLite2，并要求对照竞品。范围为首页、IP 查询、IPv6、分流、WebRTC，以及共享加载 / 错误 / 数据更新提示。既有查询与检测行为、数据 / 更新机制、三语网址、Neutral 主题不改；不借机增加下一阶段功能。沿用发布和本地提交授权，不推送。

## 改动与依据

[竞品对照与取舍](comparison.md)来自本轮实际浏览器页面。借鉴结果优先、说明后置、来源集中；不声称竞品都简短，也不复制其代码、资产或把地址相同视作确定安全的断言。优化前与竞品原始截图含真实网络信息，只存本地 ops。

- 首页 / 查询：去掉正常结果卡 GeoLite2 徽标，每页仅一处简短 MaxMind 链接；一般详情只放定位 / 网络信息，版本、字段来源和冲突对照再展开“数据来源”，资料没有删除。加载 / 不可用和示例状态仍明确标识。
- 查询：无历史时不渲染空历史区；保留现有历史不清除。有记录时短句说明浏览器本地保存，输入错误就在输入框下显示，分享与刷新行为保留。
- IPv6：默认只看状态、地址、协议与耗时，不重复解释直连 / 原生接口等；必要局限集中在默认关闭的说明内。
- 分流：常驻一行第三方会看到出口的告知；分类和分组就地呈现，短错误只在对应目标显示；并发 / 字节限制等工程细节留原任务文档。
- WebRTC：网页出口与 WebRTC 地址分层、类型使用人能读懂的标签；不重复每卡 / 每行长免责，说明按需展开，仍不把无结果写成安全或差异写成确定泄漏。
- 简 / 繁 / 英同步精简正常、错误和说明文案，三语键保持一致。复用官方 Collapsible / Card / Button / Badge，增加共用 DetectionHelp，无新依赖、无新 API。中文 AGENTS 记录后续写作规则。
