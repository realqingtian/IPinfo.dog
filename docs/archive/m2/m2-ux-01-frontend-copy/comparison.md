# 前端信息层级对照与取舍

日期：2026-11-13。本轮通过内置浏览器实际打开页面，结合当前项目五页优化前截图；仅比较内容层级和阅读负担，不评判竞品检测准确率或复制其代码、资产。截图含真实网络资料，仅存本地 ops 同任务目录。

| 对照 | 本轮实际看到的组织方式 | 本项目取舍 |
| --- | --- | --- |
| [IPFinal 首页](https://ipfinal.com/) / [检测页](https://ipfinal.com/leak) | 结果以字段 / 表格呈现；首页整体功能多，部分检测卡仍带整段解释；供应商归属说明集中在页尾 | 借鉴结果与来源分层；不复制其长页功能或把同国家 / 同地址写成确定安全的判断 |
| [IPCheck](https://ipcheck.ing/#/) | 同级双栈卡、字段明晰，原理说明较长；SDP 日志为折叠入口 | 借鉴按需查看技术资料，不模仿常驻的长说明；不在产品页展示 SDP / 工程参数 |
| [IPX 首页](https://ipx.al/) / [WebRTC](https://ipx.al/webrtc) | 先给地址 / 对照结果，相关知识在下方链接和默认折叠问答；来源单独放在对照表 | 结果优先，必要说明按需展开；保留我方“不同不等于确定泄漏”的边界，避免把差异一律写成泄漏 |

## 本项目原问题与修改

- 首页 / 查询：卡头 GeoLite2 与页尾来源重复；技术版本 / 字段来源混在一般详情。改为正常卡无供应商品牌标签，每页只留一处 MaxMind 来源链接；详细来源再展开，数据仍完整可追溯。
- 查询页：空历史标题、记录规则和空结果解释同时出现。无记录时不显示历史区；有记录只留简短的本地保存说明。输入 / 错误 / 查询 / 结果链接仍在原位。
- IPv6：每卡都解释直连、原生接口、可信入口等实现细节，还重复页级限制。改为地址、状态和耗时；必要结果边界合并为一处按需说明。
- 分流：请求方式、并发 / 超时、汇总 / 分类规则和“不是解锁”分散多段。常驻只保留第三方会看到出口的短提示；结果 / 分类直接可操作，解释放一处。失败在对应目标旁简写。
- WebRTC：STUN 完整 URL、ICE 类型英文、每行免责和重复双栈说明遮挡结果。改为网页出口 / WebRTC 地址、易读类型、同协议对照短句；保留必要服务告知，原理和局限只在说明中。

以上均为本轮页面观察与我方设计取舍，不声称竞品完全没有长文案，不将竞品结论作为网络事实证据。原有检测 / API / 资料与更新行为不变。
