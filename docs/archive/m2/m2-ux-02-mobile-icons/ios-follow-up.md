## 本轮实际复核

- 本机使用iPhone Safari风格User-Agent请求首页、根Apple图标、180px图标、512px普通图标与ICO，5个请求均200，MIME正确，图标SHA与v2资源一致。此前403不能当作本轮仍被拦截。
- 发布机器经公开Cloudflare域名分别使用Node / iPhone Safari风格User-Agent检查首页、ICO、根Apple图标、180px图标、512px图标与manifest，共12个请求均200。同路径资源摘要一致；首页两种User-Agent均包含v2声明，未发现按Safari返回旧版页面的证据。这是HTTP客户端模拟，不是原生Safari选图验收。见[脱敏响应摘要](ios-response-summary.json)。未新增源站直连或改动入口。
- 当前未提供Open Graph图片，但[Apple TN3156](https://developer.apple.com/documentation/technotes/tn3156-create-rich-previews-for-messages)允许使用Apple touch icon或favicon作为链接预览；没有og:image本身不能证明分享图标异常的原因。原生分享面板取图与留白仍待独立对照，没有为了消除系统留白盲目新增分享横幅。
- [WebKit公开问题315573](https://www2.webkit.org/show_bug.cgi?id=315573)说明WebCore收集图标候选，实际用途的最终选择由Safari界面进程决定；该报告仍是NEW，不能据此断言用户碰到同一缺陷。尺寸声明 / HTTP正常不等于真机一定采用该文件。
