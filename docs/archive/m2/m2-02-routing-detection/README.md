## 设计与检测依据

- IPX：紧凑连续表、出口概览、真实逐行结果；IPFinal：按用途筛选和出口聚合。本站沿用report-*字号、主题、品牌和长地址显示规则。
- 地址必须由浏览器读取目标站点返回的公共IP；跨域 /网络 /超时失败只记未取得，不伪造出口、不用服务器IP或不透明响应推断成功。
- IPv4与IPv6分开比较；同族不同出口表示分流 /多出口现象，不自动认定代理泄漏。请求耗时只描述该请求，不是ICMP延迟或业务可用性。
- 公共文档不保存真实访客地址；原始页面截图、运行网络与发布记录只留本地ops任务目录。公开QA可使用合成 /固定公共样本，并与真实网络验证分开。

## 实现

- 新增`/split`与三语导航；桌面采用出口概况、汇总与连续五列表，手机采用站点 /结果两列及完整长地址。保留三语、主题、共同查询框与品牌。
- 唯一固定目录包含参考、AI、社交、工具、开发、其他共28项目标；Cloudflare trace读IP /国家地区代码 /响应节点，两项参考读取可跨域响应头。检测请求不经过本站API，不发送查询IP，不存储结果。
- 5路并发、5秒期限、4KiB正文上限；无凭据、无Referer、拒绝重定向；支持停止、整轮刷新与单站重试，旧响应不可覆盖新轮结果。筛选和语言切换保留当前结果。
- 按地址族聚合；只有同族多个实际地址才提示不同出口。参考站点未取得或同族参考不一致时明确显示，绝不以服务器地址、opaque响应、加载图片成功推断出口。
- 隐藏沿用本站相同尺寸占位，复制与查询使用完整原地址；响应节点不当成用户城市，耗时不当作业务可用性或ICMP延迟。
