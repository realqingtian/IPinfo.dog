## 实际实现

- 主动开始、分类列表、全局出口汇总、同协议多 IP 归组、单项 / 全部重测和取消；三语、Neutral / 主题与导航沿用。首次打开不自动向第三方发送请求。
- 浏览器无凭据直连，最多四并发 / 每项六秒 / 64KiB 文本；不执行第三方脚本、不提供服务器任意目标代理、不向浏览器提供凭据。
- 超时、响应不可读、HTTP 状态、没有 IP、非法地址与过大响应分别显示；失败不进分组，不据此判断平台不可用或未解锁。
- 复制与查询链接保留完整 IP，隐藏只影响文字；诊断不写最近查询。实现与来源见 [设计记录](design.md)。

## 剩余边界与下一步

1Password 当前没有可供浏览器读取的出口响应，保留未确认，不计 34 项全成功；第三方端点随时间、地区和浏览器限制变化，不能保证未来始终 33 项成功。真实浏览器正常路径控制台无 warn / error；未模拟所有网络拓扑、单栈与全部代理 / 扩展条件。一次导航后过早点击未启动检测，状态复核后再点击正常；未据此修改其他页面或把未确认原因写成供应方故障。

新增页的用户视觉反馈待取得，不借用 M1 确认。M2 后续 DNS / WebRTC 和环境功能尚未实现，下一项先核对相关探测资源，不在本项偷偷增加探测或注册服务。
