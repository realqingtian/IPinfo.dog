## 改动

- 对照[IPX分流页](https://ipx.al/split)与[IPFinal分流页](https://ipfinal.com/split/)的当前说明，表达重点是网站走哪个IP及检查分流规则。本站独立改写，不直接照搬文案或给出无依据的“规则全部生效”结论。
- “已观测出口 /检测覆盖 /本轮观察 /同族参考”等改为“不同出口 /检测进度 /检测结果 /暂无可对比的IP”；主说明改“查看不同网站走哪个IP，检查分流规则是否生效”。底部只保留网站可能限制检测、没有IP不代表不能访问的简短说明。三语同步，其他翻译命名空间不改；56项Routing键与参数渲染逐语种核对通过。
- 手机原导航底与搜索框顶实测重合，间隔0px；三页共用搜索槽现在上 /下各8px，输入框仍44px高。移动导航单项44px高，整头153px，报告滚动锚点168px，防止定位到报告时被遮住。
- 导航去除大灰色选中胶囊，用600字重 /2px下划线区分当前页。输入框聚焦为中性描边与2px浅灰光圈。
- 协议切换由19px /11px字调整为36px /13px字，104px总宽、48×28px按钮与48×44px命中区域；灰色底槽、卡片色共享滑块 /细边 /轻阴影。保留380ms滑动 /300ms文字、减少动态效果、Radix方向键移动焦点 /空格选中和双协议独立结果。
