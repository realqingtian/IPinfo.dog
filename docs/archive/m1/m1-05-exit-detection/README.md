## 目标与授权

用户要求先提交，再继续下一项。开始时工作区干净，M1-04 已提交 b73626b，没有创建空提交。本任务实现首页独立 IPv4 / IPv6 探测与资料补齐，沿用测试后部署及本地提交授权；不推送。

## 实际改动

- 首页去掉示例，真实获取两个直连端点的基础地址，再独立补齐本地三库资料。单边超时不阻塞另一张卡；资料失败仍保留地址、复制和隐藏操作，可只重试资料。
- 全刷新、单卡刷新、独立错误与重试、刷新保留隐藏状态、迟到响应防覆盖；自动出口不写手动查询历史。两卡仍为 Neutral 默认组件、同级字号、桌面并排 / 手机纵向，三语共用网址。
- 新 Node 探测路由、认证入口头、精确 CORS、无共享缓存与有界请求预算；Compose secret 挂载，主站原 Cloudflare 入口限制保留。只有 v4 / v6 的探测路径公开，未新增端口或改 DNS / 防火墙。
- [接口与运维模板约定](api.md)记录可信链、错误 / 预算、配置与首次入口更正。部署私有凭据、服务器路径和原始地址证据仅在本地 ops。
