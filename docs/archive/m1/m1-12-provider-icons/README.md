# M1-12 服务商图标与统一页脚

日期：2026-11-16。状态：实现、工程 /浏览器 /发布验证完成，已上线；新版视觉反馈待取得。本地提交已获授权，未推送。

## 目标与实际改动

用户要求在服务商名称旁显示网站小Logo，随后明确移除“来源说明”展开区，将数据来源放网站页脚，并移除卡片底部“定位仅供参考”整条灰色底栏。本轮覆盖我的IP /IP查询，保持自己的品牌、现有布局、三语、主题和真实多源。

- 摘要中的服务商名称前加16px favicon；只使用同一IP、相同ASN的IPinfo as_domain，不按组织文字猜官网，不跨IP /ASN配图。图标失败回退中性图标；没有有效域名则保留名称。
- 复用现有IPinfo结果，不重复查询IP资料。新增固定HTTPS服务端图标链路，浏览器只访问本站API；不把查询IP、访客请求头、Cookie或API Key转发给图标服务。
- 来源展开区及对应冗长三语文案移除；整个卡片底栏删除，不留下空占位。多源表仍保留来源行、地区 /城市 /ASN /日期和独立错误 /重试。
- 全站页脚统一列MaxMind、DB-IP Lite、IPinfo Lite、必要许可链接与图标来源。定位与在线来源处理口径缩成一句，版本 /逐字段来源继续保留在后端接口和本地运维记录。
- Avatar通过Bun调用官方shadcn CLI添加，读回检查；package.json /bun.lock未改变，没有替换品牌素材或改变依赖版本。
