## 实施边界

- MaxMind 主结果保持，额外来源分别请求、加载和重试；一个源失败不阻断主结果、其他源或手动历史。
- API 仅接受固定来源及公共 IP，统一规范化，禁止任意目标网址；IPinfo 凭据仅服务端读取，认证只用 HTTPS Bearer 头。
- 每源结果保留地区、城市、ASN / 原组织名、查询时间及可核实的数据日期。不投票合并差异，不把 IPinfo Lite 缺失城市当错误，不添加推测风险结论。
- 两页共用对照展示，按用户后续提供的 IPX 示例，桌面使用紧凑五列表格；手机保留同表、仅表内横向滑动；三语 / 主题 / 地址隐藏与现有历史语义保持。外部来源请求会将目标 IP 发给供应商，按需展开说明；本地查询不外发。
- DB-IP 单独只读目录、候选双库校验后整代原子切换；不改 MaxMind 的三库托管、定时任务和过期规则。真实库 / Key 不进入源码或镜像。
- 本地测试、真实供应商检查、浏览器验收及部署分别记录，尚未执行不填通过。
