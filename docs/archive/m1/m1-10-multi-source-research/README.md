已完成 [完整调研](research.md)：地理 / 情报来源、注册与路由、附加资料、国内库及建议展示方式。优先建议现有 MaxMind 配合 DB-IP Lite / IPinfo Lite；Cloudflare 访客地理信息仅首页使用；标签优先评估 IPLocate API。区分 API / 下载库许可，不能把免费额度当成公开 IP 查询服务授权。

验证：核对本地现有 IP 契约与 normalizer；阅读供应商官方文档、额度与条款，报告各结论就近附来源；本地相对链接 / UTF-8 / diff 检查完成。没有调用用户截图地址、下载数据库、获取凭据、注册 / 购买 / 联系供应商、操作服务器、改应用或部署。未进行源 API 的成功率、延迟或字段实测，不将供应商文档宣称写为实测通过。
