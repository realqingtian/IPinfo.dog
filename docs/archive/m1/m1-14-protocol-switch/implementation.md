# 协议探测与隐藏规则

日期：2026-11-16。

## 行为

首页按用户选择提供 IPv4 / IPv6 切换，一次展示一个协议；两个协议独立获取、保留结果与重试。默认 IPv4；IPv4 本次失败而 IPv6 成功时可自动显示 IPv6，用户主动选择后保持该选择。仅刷新所选协议；不把自动探测记入最近手动查询。

当前认证连接入口能提供对应协议时优先使用。缺少的协议由浏览器请求 [ipify 官方](https://www.ipify.org/) 的固定 IPv4 或 IPv6 专用 HTTPS 回显。请求不含查询目标、凭据和 Referer，不代理到服务器；5 秒、4KiB 上限，拒绝错误协议 / 私有地址 / 重定向并取消离页请求。第三方回显失败不影响另一协议，不能将失败说成永久无 IPv6；地址可能经过代理 / NAT64，不据此认定原生接口或真实设备所在地。

保留主域名和 API 域名；没有恢复 v4 / v6 子域、旧诊断页、DNS 或端口。页脚补充出口检测服务链接。

## 展示遮挡

用户选择 IPv4 隐藏最后两段，如 8.8.••.••。随后要求 IPv6 多隐藏一些，最终隐藏展开后的后四组、保留前四组，如：

- 2001:4860:4860::8888 → 2001:4860:4860:0:••:••:••:••
- 2001:db8:abcd:1234:5678:9abc:def0:1234 → 2001:db8:abcd:1234:••:••:••:••

连续零只在可见前缀压缩，窄屏按组换行；标题与辅助文本都使用遮挡值。复制完整 IP、结果链接、查询输入和历史仍使用原地址。这是展示隐藏，不是清除浏览器中的原始查询资料。

## 测试范围

新增 8 项回归覆盖两个协议的固定端点 / 信任优先级 / 响应限制 / 超时与取消 / 失败隔离、IPv4 和 IPv6 遮挡及换行。三语目录格式化回归同步 segments 参数；曾因遗漏参数导致该测试失败，补全后最终 142 / 142 通过，未跳过失败项。

内置浏览器实际取得两种出口并切换，手机 390px 无横向溢出；IPv6 刷新后切回 IPv4，原结果仍可用。最终四组遮挡和复制完整 Google IPv6 已再次验证。真实出口截图仅在本地 ops；[固定样本手机遮挡](local-mobile-v6-masked.jpg) 可公开。

实现、正式发布与用户真机验收分开。IPv4-only / IPv6-only 原生浏览器、代理差异与 OS 减少动态效果变化没有全部实测，不能标记为全环境通过。
