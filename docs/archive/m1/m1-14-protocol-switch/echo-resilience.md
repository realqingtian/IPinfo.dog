# 双协议备用回显与出口对照

日期：2026-11-16。状态：实现、预发布真机、服务器发布、公网与同机正式回归完成。

用户授权为IPv4 /IPv6补充独立备用回显、自动恢复、真实USB设备验证，通过后发布并归档。后续确认保持主域名 /API两个域名，第三方地址列出口对照；卡片的地理 /ASN资料继续本地MaxMind，不使用回显服务的地理数据。用户进一步要求参考多家竞品，不写死“本站永远最高”。

## 采用方案

每个协议独立、并行请求自有连接入口和两个固定协议回显：ipify JSON、ident.me纯文本。全部公共地址 /协议校验通过才可用，每项5秒 /4KiB；不带凭据 /Referer、不允许重定向，不接收任意URL。首个有效地址固定为本轮结果，后到结果只进入出口对照，不反复替换主卡或混合不同出口的资料；刷新 /离页取消，旧代结果隔离。

本站连接使用另一协议时，不将其填入当前协议；对照显示当前连接协议。某个来源失败不会阻塞其他有效来源。最坏检测窗口约5秒，不逐个累积长等待。所选IP仍通过自己的IP接口、本地MaxMind查询，MaxMind是卡片主资料；DB-IP /IPinfo保持原有地理对照。

首页右侧地理多源表下增加独立出口表：本站 /ipify /ident.me，列来源 /地址 /状态。未知、失败或不同出口不解释成泄漏或不安全；地址不同保持原样。独立查询页只查询输入目标，不调用这些“我是谁”回显，不把访客出口混入任意目标资料。隐藏开关同步遮挡对照地址，仍保留主IP完整复制。

## 参考与取舍

- [IPX](https://ipx.al/)：实际页面区分地理多源与浏览器出口；公开脚本用不同协议的第三方回显补齐地址，并优先可用IPv4。并非所有情况下本站地址绝对优先。
- [IPFinal](https://ipfinal.com/)：实际页面区分聚合资料与各网站看到的出口；没有依据公开页面断言其内部固定优先级。
- [IPCheck.ing](https://ipcheck.ing/)：实际页面将多探针获取地址和按数据源查地理资料分开。
- [ipify官方](https://www.ipify.org/) /[ident.me官方](https://api.ident.me/)：只使用明确IPv4 /IPv6端点，避开双栈通用端点。没有复制竞品源码、评分、诊断页或重新扩展已删除的功能。
