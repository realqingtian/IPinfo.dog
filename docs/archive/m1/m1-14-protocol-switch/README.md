日期：2026-11-16。状态：实现、工程、正式发布与当前可执行浏览器回归完成，用户新版视觉 / 真机反馈待取得。

用户确认首页 IPv4 / IPv6 切换；IPv4 隐藏末尾两段，随后要求 IPv6 多遮一些，最终遮展开后的末尾四组、保留前四组。仅扩充我的 IP / IP 查询，不恢复其他页面、旧子域或规划。复制与结果链接使用完整公共 IP。实现依据与测试边界见 [说明](implementation.md)。

## 实际交付

首页两族独立探测 / 查询 / 重试并保留结果，一次显示所选协议。可信自有入口优先，缺少的协议使用浏览器固定 ipify 协议回显，失败不影响另一族；5 秒 / 4KiB、协议 / 公共地址校验、不带凭据、不代理探测。页脚保留服务来源。IPv4 / IPv6 局部隐藏同步标题和辅助文本；三语支持，窄屏按组换行。

与 [M1-13 动效](../m1-13-loading-motion/README.md) 一起发布为 `m1-14-5cc5dbfe9ba2`，Web healthy。沿用现有人工源码上传 / Docker 构建 / 正常网络候选 / Compose 发布，没有修改 Caddy、数据库状态、更新器或调度。原始服务器输出只在本地 ops。
