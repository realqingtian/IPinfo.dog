## 实际改动

- 只保留 `/`、`/ip?ip=...` 两个业务页面。移除 IPv6 检测、分流、WebRTC、环境、DNS 的导航 / 页面 / 接口 / 测试 / 文案和开发归档；删除未来路线图及初始化规划归档。[删除清单](removals.json)；保留历史核心执行与已批准品牌资料。
- 首页用一张卡显示当前 API 连接的公网 IP 与 IPv4 / IPv6 标记、刷新 / 复制 / 隐藏 / 详情。单个双栈域名不保证同时取得两种出口，不再依赖独立子域。
- 手动查询保留 IPv4 / IPv6、结果链接、最近 10 次成功主动查询及清空；URL 打开与自动出口不写历史。三语 / Neutral 主题 / 品牌不变。
- `ipinfo.dog` 只提供页面，`api.ipinfo.dog` 只提供核心 `/api/*` 与健康端点；CORS 只允许准确主站 Origin、无凭据。Caddy 验证 Cloudflare 来源并覆盖认证 token / 地址，不信任访客伪造头。
- MMDB 和每日 03:00 独立更新保持，未下载数据库、修改证书、DNS 或防火墙。
- 重写 AGENTS、README、PROGRESS、归档索引，当前范围不再引用已丢弃的全量竞品复刻规划。
