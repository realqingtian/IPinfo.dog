# M1-04：独立 IP 查询页

日期：2026-11-13。状态：实现、测试与部署验证完成；用户成品视觉待确认。

## 目标与授权

用户要求继续下一项。接真实 API，完成回车 / 按钮、错误重试、并发竞态、链接刷新 / 前进 / 后退、最近十次成功手动公共 IP 查询；沿用测试后部署与本地 Git 提交授权，不推送。首页自动出口仍归 M1-05，国际化目录名称、Neutral 基线与原始品牌不变。

## 设计与验证边界

保留现有页头、紧凑表单和结果卡。查询页去掉示例提示，首页仍明确示例；查询结果显示真实来源 / 数据版本 / 时间，缺失不补造。历史仅保存在本浏览器，标准化去重、最多十条、可清空，自动出口 / 无记录 / 失败不收录。

适用 A05–A08 及 A10–A13 回归。实际运维证据放本地 ops 同任务目录。

## 实际实现

- 查询页通过同源 API 显示真实资料，首页继续明确示例；查询页不自动识别自己的出口。表单使用原有 shadcn Field / InputGroup，继续 Neutral 默认风格。
- URL 只携带一个目标 ip。回车 / 按钮标准化提交，支持分享链接、刷新、前进后退；重复 / 非法参数明确报错，不选取其中一个目标。
- AbortController 取消旧请求，递增序号再阻止忽略取消的旧响应覆盖结果或写历史。客户端最多等待 12 秒；空输入、非公网、无记录、资料不可用、超时和限流分别说明，可重试错误提供重试。
- localStorage 仅保存成功主动手动查询的标准 IP，最多十条，去重 / 最近优先 / 可清空，跨标签页同步；不保存资料对象、自动出口、失败或无记录。存储不可用仅影响持久保存，清空失败会明确提示。
- 链接恢复与主动提交分开：初次打开 / 刷新 / 前进后退只恢复结果，不写历史。因此清空后即使刷新一个有效结果 URL，也不会重建旧记录。早期实现发现此边界后已补测修正。
- 结果卡真实显示定位 / 注册地区、缺失字段、来源冲突、逐字段来源、三库构建时间与本次查询时间；长地址可换行，完整原值与分享链接可复制。
