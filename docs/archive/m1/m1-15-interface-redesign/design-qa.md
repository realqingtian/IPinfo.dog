# IPX 风格验收

2026-11-17。目标由用户明确指定为 IPX 的风格与字体，同时保留 IPinfo.dog 的 Logo 与角色。正式版本 m1-15-ipx-954488e1feac；只核对现有两个页面，不复刻评分、地图、风险等扩展功能。

## 对照依据

内置浏览器实测 [IPX 公共查询](https://ipx.al/8.8.8.8) 的 1440 /390px 页面与 computed 字体。正文13px /19.5px，栏目12px /600，表头11px /500，IP30px /24px /600，系统字体与 SF Mono 等宽回退；浅深表面、圆角、细线与紧凑行距已写入 UI-STANDARDS。字体随操作系统回退，与 IPX 一样不下载字体。

查看了[完整手机并排](references/ipx-mobile-style-comparison.jpg)与[表格并排](references/ipx-table-style-comparison.jpg)：背景、报告表面、字体层级、细分隔线、数据密度与连续阅读方式一致。本站按既有要求保留矩形4:3国旗、完整AS前缀、品牌字标、44px手机触达；内容数量与能力取决于真实接入来源。
