## 问题与修复

用户截图显示点击“IP查询”进入空的/ip，只有标题与历史。原因是导航没有携带目标，查询页在没有目标时也没有提示卡。

- 首页导航携带当前所选IPv4或IPv6的真实地址进入查询，保留信息卡与多源对照。所选协议尚无地址时清空导航目标，避免借用另一协议地址。
- 查询页重复点击当前导航保留目标，刷新及浏览器前进后退恢复对应报告。
- 直接打开空/ip显示“查询IP信息”提示卡，明确可输入IPv4或IPv6。没有虚构IP、假加载、自动访客回显或自动查询历史。
- 导航地址只保存在本页面Provider内存，不新增持久记录或服务端共享状态。两页搜索仍复用同一表单，保留原生GET回退及输入校验。
