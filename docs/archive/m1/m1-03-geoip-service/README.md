日期：2026-11-13。状态：实现、测试与部署验证完成。

## 目标与授权

用户要求继续推进。按路线图实现指定 IP 到本地三库的共用服务与 GET /api/ip，沿用测试后部署和本地 Git 提交授权，不推送。国际化目录保持原样，不提前接入 M1-04 页面真实查询、历史或 M1-05 访客出口。

## 实施边界

- 严格解析单目标，统一 IPv4-mapped IPv6；非公网不生成归属资料。
- City / Country / ASN 统一返回字段、来源、数据版本和缺失；注册地区不替代定位，两个定位来源冲突单列。
- 服务端缓存按标准化 IP 与完整数据集隔离，容量 / TTL 有界；固定错误码、响应 no-store、运行就绪与数据未就绪分开。
- 本轮只建立服务共享读者，不安装正式更新任务或声称更新热切换已验收。

## 实际实现

- 单个 Node 进程共享完整初始 MMDB 快照，健康检查与查询共用读者；失败 5 秒退避，等待有上限。
- 服务规范化三库结果，逐字段记录来源、缺失与 Country / City 冲突；保留注册地区与定位地区的区别。
- 资料 LRU 缓存最多 512 项 / 300 秒，规范 IP 与数据集身份隔离，返回新副本和本次时间。
- GET /api/ip 只收一个 ip；固定错误状态、no-store、CORP same-origin、无 CORS 授权。全进程 120 次 / 60 秒预算，不伪称已完成每访客可信来源限流。
- 增加 /api/health/live；资料未配置也返回 readiness 503，修正原先只返回 200 的行为。
