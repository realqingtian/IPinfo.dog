日期：2026-11-13。所属任务：M1-07，关联 M1-03 / 04 / 05。状态：已确认现有实现与线上生效。

用户要求地名缺少当前语言时回退英文，并用于当前查询前端。核对现有 src/features/ip/presentation.ts 与共享 IpResultCard，国家 / 注册国家、省份 / 城市均已接入同一回退函数；首页和独立查询复用该卡片。无需新接翻译服务或改写数据库。

本轮复核现有相关测试与线上实际三语显示；不把“已有实现”写成新增代码，不为无代码变化重复部署。英文仍缺失时国家保留 ISO 代码，其余显示当前界面的未知文案；ASN 和组织原名不翻译。

- 该目标缺少城市 / 省份，繁体实际显示“未提供”，没有用注册国家或其他地名补写；注册地区同样按语言回退。
- 首页现有真实双栈结果在繁体界面显示英文国家 / 城市，原始访客地址保持隐藏；不公开归档其地址或原始地理样本。
