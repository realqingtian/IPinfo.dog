# 综合验收修复与兼容

日期：2026-11-13。

## 同内容坏库恢复

此前更新器按候选内容 ID 判断无变化。如果磁盘当前目录损坏，官方工具修复了暂存副本、候选 ID 又等于原健康版本，更新器会丢弃副本，仅延长成功时间，磁盘损坏仍存在。已先加入反例并观察失败，再修正实现。

state.json 保持 schema=1 / active 内容 ID，增加可选 folder。旧状态缺省 folder=active；修复同内容时，健康三库发布至 `<内容 ID>-<12 位随机十六进制>` 新目录，成功校验后一次性替换状态指针。普通新内容继续使用哈希目录，无变化且原目录完整时不搬移。原目录从不逐文件覆盖；只有不再被状态指向后清理。内存 Buffer 保留旧请求，资料缓存仍按内容 ID 隔离，同内容无需改事实缓存。

读取器支持旧状态、严格检查新目录名与 ID 前缀，切换加载时复查指针；失败退避按物理目录区分，修复后的新代次不会被坏目录的退避挡住。真实三库测试在临时目录破坏 City、恢复相同内容、确认 ID 不变而物理目录改变、冷启动成功。生产数据未人为破坏。

升级次序为先发布新 Web 读取器，再切换更新镜像；旧 M1-06 读取器不识别修复代次，不直接回退旧读者读取新状态。原 M1-06 状态已在禁网候选与正式环境验证兼容。

## 官方检查范围

每次运行先验证配置仅有 AccountID / LicenseKey / EditionIDs，恰好覆盖 City / Country / ASN；不接受重复或遗漏、Host / Proxy 等覆盖。路径由部署参数控制，凭据只读挂载给独立更新容器。失败固定返回 UPDATE_FAILED，不公开配置内容。

## 界面与三语

新增 name=ip / translate=no；仅在用户主动提交非法目标后聚焦输入，不因打开分享链接强制弹出键盘。首页每协议独立 polite 区域，不把一边的失败变成另一边失败。两页 SSR 描述与语言切换同时更新描述 / 标题 / html lang，网址、草稿和结果保持。

不更换已确认的布局、字体层级或颜色；没有新增库、服务、登录或外部监控。
