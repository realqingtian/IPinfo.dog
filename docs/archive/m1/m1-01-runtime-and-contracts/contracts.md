# M1 基础契约

日期：2026-11-13。除健康检查和读取器兼容边界外，以下为后续任务的固定契约，不表示完整查询 / 出口接口已经上线。

## 地址与字段

单个 IPv4 / IPv6 字面量，裁剪首尾空白，最长 45 字符；拒绝域名、URL、CIDR、方括号、zone、旧式整数 / 十六进制和歧义 IPv4 前导零。IPv4-mapped IPv6 还原成 IPv4 再判范围；IPv6 压缩规范化。特殊过渡范围保留分类，不直接当普通公网。

非公网在查询入口报告地址类型，不伪造公网归属。兼容性测试直接查保留地址用于确认无记录，两者是不同层。定位国家与注册国家分开，不能用注册国家或组织名补定位 / 住宅属性；缺失用 null，冲突和各字段来源明确列出。

类型见 src/lib/contracts/ip.ts：地址 / 协议、定位 / 注册国家、城市 / 省份、ASN / 组织、数据集标识、每源构建时间与查询时间。字段部分缺失仍可成功。

## 端点与错误

| 端点 | 契约 | 归属 |
| --- | --- | --- |
| GET /api/ip?ip=... | 仅单个 ip 参数；400 INVALID_IP、422 NON_PUBLIC_IP、404 NO_RECORD、503 DATA_UNAVAILABLE、504 TIMEOUT、429 RATE_LIMITED；成功返回 IpResponse | M1-03 / 04，尚未实现 |
| GET /api/exit | 不允许指定目标；按可信入口的连接来源返回基础 IP，不等资料；双栈子域约束协议，伪造转发头无效 | M1-05，尚未实现 |
| GET /api/health | 已实现：配置三库可读 200，目录缺失 / 损坏 503；不暴露路径、异常栈、凭据或数据记录 | M1-01 |

未配置数据目录时健康检查返回 not-configured，不表示真实库就绪；正式部署必须挂载三库并返回 database=ready。健康 / 出口响应禁止共享缓存。

## 读者生命周期与边界

maxmind 5.0.9 / mmdb-lib 从完整 Buffer 建立内存 Reader，readFile 完成就关闭描述符；不启用每库独立监听。三库类型、IPv6 能力和哈希均验证后返回候选；候选失败不修改调用方旧数据集。旧读者在源副本删除后仍可查询，已实际验证；这不表示 M1-06 的调度、并发切换管理器或缓存失效机制已实现。

读取器对某些非法输入返回 null，因此项目查询边界先严格校验，防止把非法地址当作无记录。初次错误断言及修正保留本地记录，不修改失败输出。

缓存后续按规范 IP / 数据集隔离；语言化缓存增加 locale，自动出口不缓存。TTL、容量、超时、限流数值在 M1-03 / 05 经实测固定，不宣称未实施的保障。

历史记录只保存成功的手动公共 IP，最多 10 条、去重可清空，字段部分缺失仍可成功；无记录 / 非公网 / 错误 / 自动出口不计入。三语共用 URL，切换不丢输入、目标、结果或历史。
