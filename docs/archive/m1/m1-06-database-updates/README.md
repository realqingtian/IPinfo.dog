# M1-06：数据库更新与故障恢复

日期：2026-11-13。状态：实现、测试、定时任务安装与部署验证完成；整个 M1 仍待综合 / 用户视觉验收。

## 目标与授权

用户要求继续下一项。实现官方 geoipupdate 每天 03:00 检查、完整候选校验 / 原子切换、避免重叠 / 错过补跑、72h 警告和 30d 暂停资料。沿用香港部署及本地提交授权，不推送。服务器原发行版的通用更新器保持不动，项目使用独立任务与数据目录。

## 实际实现

- 独立官方 8.0.0 更新镜像，固定摘要、公共 CA 包和只读凭据；Web 不挂载 MaxMind 配置。Bun 打包 Node CLI，不增加依赖或锁文件。
- 完整三库在暂存区校验类型、构建时间与六次 IPv4 / IPv6 样本；不要求三库同日构建，允许可选定位字段缺失，拒绝版本倒退。预填原文件交给官方工具检查，无变化不切换；只有全部通过后原子发布完整状态。
- 托管读者按完整版本热切换，每请求捕获同一快照，缓存按 ID 隔离 / 失效；旧 Buffer 在文件退休后仍可读。失败保留有效数据，72h 提示、30d 暂停资料和缓存读取，基础出口不受影响。
- 两页新增三语状态提示，健康接口区分资料与进程；错误不公开账号、路径或供应商原文。宿主 flock 防重叠，专用 systemd timer 每日 03:00、Persistent 补跑，下载超时有界，遗留暂存 / 不再使用的版本清理。
- ESLint / TypeScript 排除本地 ops / data，避免运维辅助材料进入工程检查；Git 与 Docker 原有整目录排除继续保留。细则见 [设计与运行约定](design.md)。

## 更正与限制

初次测试修正了夹具的 5 秒退避 / 类型约束与测试副本 build_epoch 扩展类型解析；初版更新镜像缺系统 CA 包，检查发现后停止首次尝试、补入官方公共 CA，再执行成功的官方检查。不将被停止的首次尝试记录为 MaxMind 拒绝或成功；初始测试 / 构建日志保留。后续仅扩大警告措辞以覆盖状态读取 / 重载故障，最终构建重新检查过。
