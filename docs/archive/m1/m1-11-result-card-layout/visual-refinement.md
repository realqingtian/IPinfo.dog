# 结果视觉、手机布局与文字规范

日期：2026-11-16。状态：实现、工程 /浏览器 /公网验证完成，已发布；新版用户视觉接受度待反馈。沿用M1-11，服务器替换与本地提交已有授权，本轮未推送。

## 目标与审视

用户连续反馈整体视觉差、手机横向滚动、页脚重复来源、表头与列表大于栏目说明，并要求研究IPX形成规范。保留两个页面、Neutral、现有品牌、三语 /主题 /真实资料及数据请求逻辑。

原界面顶部地区和ASN摘要卡重复主摘要及网络字段；城市长值拉高来源行，出口表拉长右侧造成左下空白；固定600px宽表和溢出页脚给手机造成横向滑动。标题与表格缺少统一层级。

## 实际改动

- 对照IPX公开CSS，建立 [界面规范](../../../UI-STANDARDS.md)，并加入AGENTS的界面开发前置要求。IPX值区分CSS声明与完整浏览器实测，未把参考站崩溃后的检查说成通过。
- 共用report-*样式：主IP手机24px /桌面30px、700；栏目14px /600；正文13px /400；表头12px /500；辅助12px、许可11px。使用原有系统字体与Neutral tokens，保留品牌图标和配色。
- 删除重复地区 /ASN小卡；主摘要全宽，网络 /来源主体约0.8:1.7，减少边框强度与空白。只以IP作为视觉焦点，不增加评分或装饰卡。
- 多源桌面五列固定比例，城市列32%；手机逐来源纵向完整呈现地区 /旗帜、城市、ASN、更新 /许可。完整长文本换行，不隐藏滚动条掩盖溢出，不截掉差异。
- 出口对照桌面两个紧凑并列项、手机纵向两项，移除冗余表头；隐藏范围、完整复制、协议切换与迟到结果隔离保持。
- 页脚只留©年份与站名；来源与必要许可关联放在对应数据源行。删除三语中不再使用的页脚说明键。
- 修复查询按钮容器的负外边距，解决320px下输入组4–5px局部溢出；骨架对应新卡片比例。
- 增加 [只读UI检查函数](../../../../scripts/check-report-ui.mjs)，检查实际字号 /字重 /行高、页面及可见容器溢出、手机来源完整性、重复摘要与页脚链接；不启动浏览器，不冒充全部功能或真机验收。
