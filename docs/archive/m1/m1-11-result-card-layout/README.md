## 实际改动

- IP 摘要、网络资料和多源对照整合为同一张结果卡。桌面1120px卡宽，摘要30px，网络 / 来源双列；手机24px地址、纵向重排，国旗 / 区旗保留本地SVG。
- 查询表单、协议和复制 / 隐藏 / 刷新 / 链接共用工具条；最近查询放到结果后，不再占据首屏。表单保持挂载，提交和非法输入不丢失焦点。
- 长IPv6按完整地址组换行，复制仍为完整原地址。手机操作44×44px；只有600px多源表内部溢出，390px整页无横向溢出。
- 桌面摘要小卡只放已有定位与ASN资料，手机隐藏重复摘要；来源说明默认收起，数据版本、逐字段来源、实际日期和许可均保留。
- MaxMind / DB-IP Lite / IPinfo Lite继续独立加载和重试，失败可保留其他来源；未知字段与来源差异保持。没有把IPX的评分、原生性、风险或服务推断填入当前无可靠数据的区域。
