## 设计基线

遵守用户选定的 shadcn Neutral 默认组件，不增加新的视觉风格：浅色背景 #ffffff、前景近 #171717、次要文字约 #737373、分隔约 #e5e5e5；深色使用对应语义变量。系统无衬线用于界面，等宽字体仅显示 IP / ASN，IP 两种协议同为 20px。

内容宽度约 1120px，桌面页头一行、手机导航换行；双卡并排且字段紧凑，移动端纵向。没有大标题宣传区、额外侧栏、评分或未实现工具占位。品牌原图保持不变。结构先用默认组件，不为独特性偏离已确认需求。

```text
品牌 / 我的 IP / IP 查询                 语言 / 主题
示例提示
我的 IP                                  刷新示例
[ IPv4：地址、地区、ASN、详情 ] [ IPv6：同级信息 ]
```

查询页使用相同页头，输入与按钮在顶部，示例入口后按需显示同一结果卡；没有查询结果时不占巨大空白区。语言切换保留输入、结果和 URL；主题支持浅 / 深 / 跟随设备，首次跟随。
