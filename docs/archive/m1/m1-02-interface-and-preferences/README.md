## 设计基线

遵守用户选定的 shadcn Neutral 默认组件，不增加新的视觉风格：浅色背景 #ffffff、前景近 #171717、次要文字约 #737373、分隔约 #e5e5e5；深色使用对应语义变量。系统无衬线用于界面，等宽字体仅显示 IP / ASN，IP 两种协议同为 20px。

内容宽度约 1120px，桌面页头一行、手机导航换行；双卡并排且字段紧凑，移动端纵向。没有大标题宣传区、额外侧栏、评分或未实现工具占位。品牌原图保持不变。结构先用默认组件，不为独特性偏离已确认需求。

```text
品牌 / 我的 IP / IP 查询                 语言 / 主题
示例提示
我的 IP                                  刷新示例
[ IPv4：地址、地区、ASN、详情 ] [ IPv6：同级信息 ]
```

查询页使用相同页头，输入与按钮在顶部，示例入口后按需显示同一结果卡；没有查询结果时不占巨大空白区。语言切换保留输入、结果和 URL；主题支持浅 / 深 / 跟随设备，首次跟随。

## 实际改动

- 用固定版本官方 shadcn CLI 加入 Card、InputGroup、Field、DropdownMenu、Collapsible 等组件，保留生成样式；新增 next-themes 0.4.6，直接依赖固定版本并更新唯一 bun.lock。
- 两页统一页头、导航、示例提示与结果卡；查询页支持示例、严格地址校验、示例链接恢复，未知公共地址不会获得伪造资料。
- 三语同网址，不增加语言参数 / 路径。服务端按 cookie、Accept-Language、英文依次决定；手动切换不导航，保留当前 React 状态。cookie 仅保存语言，主题单独保存在本浏览器。
- 第一页面默认跟随设备；浅 / 深手动选择可记住。next-themes 响应系统偏好，本轮只核对当前系统深色匹配，未模拟操作系统运行中改色。
- Docker 上下文加入三语 messages 白名单；Compose 镜像名改为可由 IPINFO_IMAGE 指定，供本次独立发布标识使用，不扩大公开端口。
