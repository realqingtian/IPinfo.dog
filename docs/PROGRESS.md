| 功能 | 范围 |
| --- | --- |
| 我的 IP | 自动取得本次 API 连接的公网地址及资料、刷新 / 重试、IPv4 或 IPv6 标记 |
| IP 查询 | 独立手动查询公共 IPv4 / IPv6、结果链接、浏览器最近 10 次成功手动查询，可清空 |
